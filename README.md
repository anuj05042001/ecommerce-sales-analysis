# E-Commerce Sales & Profitability Analysis

## Project Overview

This project analyzes e-commerce sales and profitability data to identify business performance trends, profitable categories, loss-making products, discount impact, and regional performance.

## Business Objective

The objective is to analyze sales and profitability and provide data-driven insights using Python, SQL and Power BI.

## Dataset

The dataset contains 51,290 e-commerce transactions with information about:

- Orders
- Customers
- Products
- Categories
- Sales
- Quantity
- Discount
- Profit
- Shipping Cost
- Region
- Segment
- Shipping Mode

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Power BI
- Excel

## Data Analysis

The analysis includes:

- Data cleaning
- Data validation
- Year-wise sales and profit analysis
- Category analysis
- Sub-category analysis
- Product performance
- Discount analysis
- Regional analysis
- Customer segment analysis
- Shipping mode analysis

## Power BI Dashboard

The interactive dashboard includes:

- Total Sales
- Total Profit
- Total Quantity
- Profit Margin
- Year-wise Sales Trend
- Category-wise Sales & Profit
- Discount Impact
- Top 10 Products by Sales
- Bottom 10 Products by Profit
- Region-wise Sales & Profit
- Sub-category Profitability
- Year, Category and Region filters

## Key Insights

- Total Sales: 12.64M
- Total Profit: 1.47M
- Overall Profit Margin: 11.62%
- Sales increased consistently from 2011 to 2014.
- Technology generated the highest category profit.
- Tables was a major loss-making sub-category.
- Higher discount levels were associated with declining profitability.
- Southeast Asia had a relatively low profit margin.
